## Description
This repository contains the files for Lab 09, which demonstrates connecting a MySQL database to a PHP web application. It includes a car inventory display and a search function.

## Files Included
- `cars.php`: Displays all cars from the database.
- `search_form.php`: HTML form to search for a car model.
- `search_result.php`: Processes the search and displays results.
- `settings.php`: Contains database connection credentials.
- `exhibition_db.sql`: The exported MySQL database.
- `Lab9_Screenshots.pdf`: Screenshots of query execution and results.
